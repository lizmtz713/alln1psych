# components/

**Reusable UI components.** No routes, no business logic.

Use from `app/` screens or from `features/*/` (feature-specific UI can live in `features/<name>/components/`).

**Examples:** GaugeCard, GaugeRing, InsightCard, PersonTile, MindMailCard, ToolButton, VoiceInput, ModalSheet.

See [docs/INGAUGE-REPO-STRUCTURE.md](../docs/INGAUGE-REPO-STRUCTURE.md).
