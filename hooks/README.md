# hooks/

**Reusable React hooks** (shared across app and features).

Feature-specific hooks can live in `features/<name>/hooks/`; put here when used by multiple domains.

**Examples:** useGaugeSignals, useVoiceInput, useUserProfile, useCheckin, useInsights, useTalk.

See [docs/INGAUGE-REPO-STRUCTURE.md](../docs/INGAUGE-REPO-STRUCTURE.md).
