# Red Flag / Green Flag Tool — Science-Based

## Overview

A relationship assessment tool that helps users recognize healthy (green) and concerning (red) patterns in relationships, grounded in attachment theory, Gottman research, and respect/accountability literature.

---

## 🚩 RED FLAGS (5 Categories)

### 1. The Four Horsemen (Gottman — 93% divorce predictor)
- **Criticism** — Attacking character, not behavior
- **Contempt** — Disrespect, sarcasm, eye-rolling, superiority
- **Defensiveness** — Deflecting, making excuses, counter-attacking
- **Stonewalling** — Withdrawing, shutting down, refusing to engage

### 2. Attachment Red Flags
- Hot/cold cycles (intense then distant)
- Love bombing (over-the-top attention early on)
- Avoids vulnerability (never shares feelings or needs)

### 3. Respect Red Flags
- Rude to service workers
- Bad-mouths all exes
- Ignores boundaries (your no doesn’t count)

### 4. Accountability Red Flags
- Never apologizes
- DARVO (Deny, Attack, Reverse Victim and Offender)
- Repeats hurtful behavior without changing

### 5. Serious Warning Signs
- Isolates you from friends/family
- Controls finances or access
- Physical intimidation
- Threats (to you, themselves, or others)

---

## 🟢 GREEN FLAGS (5 Categories)

### 1. Secure Attachment Markers
- Consistent (words match actions over time)
- Comfortable with closeness AND space

### 2. Respect Markers
- Respects your no
- Kind to everyone (not just you)
- Celebrates your success

### 3. Accountability Markers
- Real apologies (specific, no “but,” changed behavior)
- Takes feedback without defensiveness
- Changes behavior when it matters

### 4. Conflict Markers
- Fights fair (no name-calling, no contempt)
- Stays present (doesn’t stonewall)
- Repairs after (comes back to make it right)

### 5. Growth Markers
- Does self-work (therapy, reflection, growth)
- Curious about you (asks, remembers, follows up)
- Supports your growth (not threatened by your success)

## Features

| Feature | Description |
|--------|-------------|
| **Learn Flags** | Browse all red and green flags with research backing and short explanations. |
| **Assess Someone** | Checklist assessment: select which flags you’ve noticed, add optional notes. |
| **Quick Check** | AI-powered “Is this a red flag?” — paste or describe a situation, get a grounded take. |
| **Results** | Summary of assessment (red vs green counts), recommendations, and next steps. |
| **CoPilot Integration** | “Discuss with CoPilot” — open Talk with context so the user can process the assessment. |

---

## Research Backing (for content)

- **Gottman**: Four Horsemen (criticism, contempt, defensiveness, stonewalling); repair attempts; 93% divorce prediction.
- **Attachment**: Secure vs anxious/avoidant; consistency, vulnerability, hot/cold as insecure markers.
- **Respect/Accountability**: Boundary respect, apology research (specificity, behavior change), DARVO (Freyd).
- **Safety**: Coercive control, isolation, financial control, threats — link to domestic violence and safety resources where appropriate.

---

## UX Notes

- Non-clinical language: “patterns” and “flags,” not diagnostic labels.
- Normalize: “Everyone has some red and green. This helps you see the full picture.”
- Results are for reflection and conversation (e.g. with CoPilot), not a “score” or verdict.
- If serious warning signs are selected, include a gentle nudge toward safety/resources (e.g. National Domestic Violence Hotline, 988 if relevant).
