# Critical Thinking Tool — Spec

## Overview

A tool to help users recognize logical fallacies, cognitive biases, and misinformation tactics — and to evaluate evidence quality. Supports learning, AI-powered analysis of text/images/URLs, and practice with daily challenges and progress.

---

## 📚 LEARN (70+ items)

### Logical Fallacies (30+)
- Ad Hominem, Straw Man, False Dilemma
- Appeal to Authority / Emotion / Popularity
- Slippery Slope, Red Herring, Tu Quoque
- Begging the Question, Hasty Generalization
- …and more (see data)

### Cognitive Biases (25+)
- Confirmation Bias, Anchoring, Dunning–Kruger
- Bandwagon Effect, Halo Effect
- Sunk Cost Fallacy, Loss Aversion
- …and more (see data)

### Misinformation Tactics (15+)
- Emotional Headlines, Missing Context
- Gish Gallop, Astroturfing, Deepfakes
- Bot Amplification, False Equivalence
- …and more (see data)

### Evidence Evaluation
- Evidence hierarchy (anecdote → meta-analysis)
- Evidence vs opinion checklist
- Source credibility signals

---

## 🔍 ANALYZE

User submits for AI analysis:
- **Text** — Paste argument, claim, or article excerpt
- **Image** — Screenshot, meme, headline
- **URL** — Article link (as text for context)

AI identifies:
- Fallacies present
- Bias indicators
- Manipulation tactics
- Evidence quality
- Questions to ask (to probe or verify)

---

## 🧠 PRACTICE

- **Daily challenges** — “Spot the fallacy” (or bias/tactic); user sees a short example and chooses the correct label.
- **Progress tracking** — Correct count, streak, history.
- **Mastery badges** — e.g. “5 in a row”, “10 fallacies spotted”, “First bias spotted”.

---

## Entry Points

- **Toolkit** — Pill on home (e.g. “Think” or “Critical Thinking”).
- **News My Way** — Link or button to “Analyze this with Critical Thinking” / “Check this claim”.
- **CoPilot** — When user pastes a claim or asks “is this valid?”, suggest the Critical Thinking tool or run analysis in-conversation.

---

## UX Notes

- Non-judgmental: “This helps you think clearly” not “You’re wrong.”
- Learning first: LEARN tab before ANALYZE so users have a shared vocabulary.
- Analyze output should be structured (fallacies, biases, tactics, evidence, questions) and concise.
- Practice should feel low-stakes and rewarding (badges, streak).
