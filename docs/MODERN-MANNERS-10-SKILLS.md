# Modern Manners: 10 Skills Research Says Matter Most

**Purpose:** A research-backed curriculum layer for interpersonal skills that improve relationships and societies. Not etiquette rules (forks, greetings)—*prosocial behavior, respectful communication, and social–emotional skills* that experts across psychology, sociology, and communication science agree are foundational.

**Core idea:** Respect + empathy + responsibility. Everything else builds from those.

**Format in the app:** 1 idea → 1 example → 1 practice tool. Micro-learning (20–40 seconds per skill in the hub); deep practice via existing tools and lessons.

## Universal Principles (Across Cultures)

Research converges on a small set of norms that appear almost everywhere:

- **Respect for others** — Dignity, listening, not humiliating. → Listening, validation, respectful disagreement.
- **Reciprocity** — Mutual exchange, thank you, acknowledging help. → Gratitude.
- **Fairness** — Taking turns, keeping agreements, admitting mistakes. → Responsibility, repair.
- **Empathy** — Understanding another's emotional state. → Validation, empathy, Tone Check.
- **Self-regulation** — Managing impulses; pausing before reacting. → Quick Reset, Tone Check.

## How the App Teaches Them

- **Tools:** Tone Check, Repair Builder, Reach Out, Relational Bridge, After the Fight, Role Play, Quick Reset.
- **Lessons:** Relationship repair micro-lessons (`/learn/relationship-repair`): defensiveness, apologize, validate, start hard convo, repair after fight, compromise.
- **Hub:** `/learn/modern-manners` — 10 cards, each with one idea, one example, and links to Learn + Practice (tool).

**Pattern:** Awareness → Pause → Respectful communication → Repair if needed. Fits Signals → Tools → Reflection.
